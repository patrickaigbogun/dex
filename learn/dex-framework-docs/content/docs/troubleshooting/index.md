# Troubleshooting

Common issues and solutions for Dex apps.

## Topics

- [Common Errors](./common-errors) — Build and runtime errors
- [Path Issues](./path-issues) — Routing and config problems
- [Build Failures](./build-issues) — Compilation and bundling issues

## Quick Fixes

| Problem | Solution |
|---------|----------|
| Port in use | Change `PORT` env var |
| Routes not updating | Restart dev server |
| Layout not showing | Check `web/layouts/` structure |
| 404 on refresh | Ensure SPA fallback is enabled |
