# Dex (Human Docs)

Dex is a **composable, Bun-first framework** where the “framework” is a set of small packages you assemble into an app.

The goal is a composable development environment: each capability lives in a package, and you opt into it explicitly. Dex is still early (0.x) and not fully composable yet, but it’s moving in that direction.
