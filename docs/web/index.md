## What this docs set focuses on

- Explaining Dex in plain language first.
- Showing how the packages fit together.
- Describing conventions and mental models before implementation details.
- Helping new maintainers understand what is stable now vs what is planned.

## Audience

This docs set is written for:

- Developers evaluating Dex for the first time.
- Team members joining an existing Dex project.
- Maintainers who need a clear architecture and workflow reference.

## Scope

This documentation covers framework concepts and practical usage patterns.
It intentionally avoids deep internal source walkthroughs unless needed for understanding.
