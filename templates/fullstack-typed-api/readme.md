# Fullstack Typed API Template

Demonstrates end-to-end typesafety between Elysia API routes and the React frontend using `@dex/pie` and `@dex/validation`.

## Features
- Elysia API route with `@dex/validation` body validation
- `@dex/pie` fully typed client client generated automatically via `dex.config.ts`
- React task list UI consuming `api.tasks.get()` and `api.tasks.post()`
